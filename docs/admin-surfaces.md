# 小程序与 PC 后台边界

## 微信小程序：用户内容管理

- 查看本人绑定的 S3 设备
- 选择教育、养老及通用 Demo 模板
- 编辑内容并指定 A 屏、B 屏或双屏
- 推送内容并查看本人设备的历史记录
- 管理个人连接与通知设置

小程序不提供平台密钥、全量用户、全量设备、插件审核、模板上下架或运营统计。

## PC：运营管理

- 全量设备与在线情况
- 全量内容任务及执行状态
- 模板新增、编辑、启停与分类
- 插件安装、审核、启停与兼容性状态
- 用户、租户、应用和权限（M1）
- 审计日志、运营统计、告警和 OTA（后续版本）

## 权限原则

移动端使用用户令牌，并由服务端校验设备归属；PC 使用独立管理员身份。两类接口分别位于 `/api/v1/mobile/*` 与 `/admin/v1/*`，不依靠前端隐藏按钮实现权限隔离。
