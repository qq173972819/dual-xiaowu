# 森穹小悟 · 一体双屏学习墨看板 微信小程序

> 配套硬件：一体双 4.2 寸墨水屏学习看板（ESP32-S3 双屏固件）
> 配套后台：Web 管理后台（`dual/` 管理台 + 官方后端）
> 本文档对应产品 PRD《森穹小悟 · 一体双屏学习墨看板 全套PRD V1.4》第七节「微信小程序原型」

本目录是一个**可直接用微信开发者工具打开、真机预览、最终发布**的微信小程序原生工程（无第三方框架依赖），实现 PRD 中定义的**家长通道**与**老师通道**两条核心链路。

---

## 一、功能范围（对齐 PRD 第七、十二节）

### 家长通道（主账号）
- 微信一键登录（免密，wx.login 换 token）
- 多设备选择（铠泽 / 妹妹的墨看板）
- 首页看板推送入口
- 推送【今日作业】：文本粘贴 / 拍照 OCR 识别；追加或覆盖
- 推送【通知便签】：来源标签（家长备注 / 老师通知）；过期策略（当日消失 / 持续展示）
- 推送历史归档：筛选、复制复用、删除
- 立即同步 A 屏（5 分钟限流，墨水屏保护）

### 老师通道（免注册，授权码登录）
- 输入 6 位家长下发的授权码，免注册进入
- 仅可「布置今日作业（追加）」与「下发通知便签」
- 权限锁死（与 PRD 权限矩阵一致）：
  - ❌ 不可覆盖作业（仅追加）
  - ❌ 不可设置持续便签
  - ❌ 不可查看归档
  - ❌ 不可切换设备

### 与 dual 后台的职责边界
| 能力 | Web 后台（dual/） | 本小程序 |
| ---- | ---- | ---- |
| 学段、模式、A/B 归属配置 | ✅ | ❌ |
| 课程表、倒计时、考试历录入 | ✅ | ❌ |
| 老师授权生成、冻结 | ✅ | ❌（仅消费授权码） |
| 作业、便签每日推送 | ✅（兜底） | ✅（主推） |
| A 屏一键同步 | ✅ | ✅ |
| B 屏强制刷新 | ✅（仅后台） | ❌ |
| 归档导出 CSV | ✅ | ❌ |

## 二、本地运行（无需后端，开箱即演示）

1. 安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 「导入项目」→ 选择本 `miniprogram-xiaowu/` 目录。
3. AppID 选择「测试号」（项目已配置 `appid: "touristappid"`，可直接以游客身份运行）。
4. 编译即可在模拟器走完全部流程。**默认 `useMock: true`**，所有数据落在本地 Storage，无需任何后端。

> 演示提示：老师授权码输入 `123456` 即可进入「铠泽的墨看板」推送面板。

## 三、接入正式后端

小程序与后端之间由 `utils/api.js` 统一收口，接口严格对齐 PRD 第六节「接口摘要」：

| 方法 | 路径 | 说明 |
| ---- | ---- | ---- |
| POST | `/api/auth/wechat` | 家长微信登录（code 换 token） |
| GET  | `/api/device/list` | 家长设备列表 |
| POST | `/api/push/homework` | 推送今日作业（覆盖/追加） |
| POST | `/api/push/note` | 推送通知便签 |
| GET  | `/api/push/history` | 查询历史推送记录 |
| POST | `/api/auth/verify` | 老师授权码校验 |
| POST | `/api/device/<sn>/sync` | 立即同步 A 屏（限流） |
| GET  | `/api/device/snapshot_a?sn=` | A 屏快照（预览） |
| GET  | `/api/device/snapshot_b?sn=` | B 屏快照（预览） |

接入步骤：
1. 在 `app.js` 中将 `globalData.useMock` 改为 `false`，并填写 `baseURL`（你的后端域名）。
2. 在[微信公众平台](https://mp.weixin.qq.com) → 开发 → 开发设置 → **服务器域名** 中，把后端域名加入 `request 合法域名`（本地开发可在开发者工具「详情 → 本地设置」勾选「不校验合法域名」）。
3. 后端需实现上表接口（PRD 第五节数据表 `push_record` / `teacher_auth` 已给出字段）。当前 `backend/` 已实现设备绑定与 `dual-config` 存储，推送类接口可在此基础上扩展。

## 五、设计说明

- 视觉采用**官网同款纸感配色**：纸白 `#f3f0e7` 底 + 墨黑 `#11130f` 主色 + 官网灰系边框（`#c9c7bf`），契合「无蓝光、类纸质感、纯信息看板」的产品定位；启动页使用官方墨滴猴子 logo（`images/logo.png`）。
- 推送前提供「模拟 A 屏排版」预览，所见即所得，避免上屏排版溢出（对应 PRD 风控第 4 条）。
- 所有写操作（推送、同步）均带限流与确认，保护墨水屏刷新寿命（对应 PRD 风控第 2、5 条）。
