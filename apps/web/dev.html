设备认证、双屏内容配置下发、待办与屏幕内容推送接口。

鉴权模型

平台提供三种鉴权上下文，互不冲突：

场景凭证典型用途
用户内容配置Authorization: Bearer <user_token>PC 后台 / 小程序读写自己绑定的设备
设备自身X-Device-Token固件拉取双屏帧、上报心跳与运行模式
运营后台X-Admin-Key管理员查看全局设备、任务与审计
设备标识统一使用 MAC（大写，去分隔符）。固件启动后先 POST /api/device/{mac}/token 领取 X-Device-Token，再凭此拉取 /api/render 的屏幕帧。

核心端点一览

方法 / 路径说明
GET/POST /api/device/{mac}/dual-config双屏内容配置读写（用户态 / 设备态）
GET /api/render?persona=DUAL_A|DUAL_B固件拉取 A 屏 BMP / B 屏 raw 2bpp 帧
GET /api/preview浏览器快照预览，返回 PNG
POST /api/push/homework · /api/push/note老师授权码推送作业 / 便签
POST /api/device/{mac}/sync触发设备立即刷新（含墨水屏保护限流）
