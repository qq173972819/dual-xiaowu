# PRD：森穹小悟 · 一体双屏学习墨看板（V1.4｜产品化定稿版）
> 硬件：一体双4.2寸墨水屏
> A屏：黑白快刷屏｜本地按键菜单交互、当日动态任务视图（本地预缓存全部视图，按键切换不上云）
> B屏：慢刷屏｜每日定时刷新1次（默认08:00），静态大盘（课程表、总倒计时、月度考试历）
> 核心新增重点：**作业/老师任务轻量化推送链路**，降低家长、老师录入成本；适配商业化产品，逻辑闭环、专业可交付
> 过滤优先级：学段过滤 → 模式 `+/-` 开关 → 模块A/B屏归属分流
> 核心原则：**家长、老师录入成本最低，能复制、能转发、能快捷输入，拒绝复杂填表**
> 按键：上 / 下 / OK；学生仅浏览，无编辑权限

## 二、三层过滤体系（保持原有，支撑自动精简菜单）
1. **第一层：学段过滤（家长设备页设置：小学 / 初中 / 高中，系统自动白名单）**
    不在学段白名单的模块，在后台隐藏、不进入菜单池
2. **第二层：模式 +/- 开关**
    学段允许的模块，家长继续开启`+` / 关闭`-`
3. **第三层：A/B屏分流（系统默认，支持手动覆盖）**
    - B屏（日更一次，08:00定时刷新）：课程表、倒计时组、月度考试历
    - A屏（快刷菜单视图，本地缓存切换）：书包物品提醒、今日作业、老师便签、背诵打卡、错题复盘、周固定任务、阅读任务、作文素材、公式速查、积分看板、护眼提示

## 三、【重点】作业 & 老师任务推送方案（轻量化，产品化核心）
> 核心结论：**双入口：家长快捷推送入口 + 老师授权推送入口；支持3种录入方式，满足不同场景**
> 推送目标：【今日作业】模块、【老师便签】模块。两个模块是信息交汇点，互不冲突。

### 3.1 推送入口载体：微信小程序（优先级高于Web后台，日常主推小程序）
Web后台用于**长期配置**（课程表、模式、学段、素材库、授权管理）；
小程序用于**每日高频推送**（作业、临时通知），手机随手发，适合家长、老师。

### 3.2 三种录入方式（由简到繁，覆盖全部场景）
#### 方式1：文本直接粘贴（最高频，主推）
家长/老师把微信群、班级群里复制好的作业文本，直接粘贴到输入框，支持换行。
示例粘贴内容：
```
数学：P42 1-12题
英语：背诵Unit8单词，听写
物理：完成周测剩余大题
```
系统自动**保留换行格式**，直接落库到【今日作业】或者【老师便签】。不需要手动选择科目、增加条目，粘贴即推送。

#### 方式2：拍照OCR识别（第二主推，解决老师发图片作业）
小程序内置OCR：直接拍摄班级群作业图片 → 识别文字 → 用户可以简单修改识别结果 → 一键推送至设备。
> 商业化备注：OCR调用按量计费，后台可配置额度；识别结果允许人工校正，防止错字。

#### 方式3：模板快捷选择（周期性任务、固定作业）
后台【素材库】支持家长保存个人作业模板。
示例模板：英语听力20min、练字15分钟。小程序直接勾选模板，一键追加到今日作业。

### 3.3 两个推送目标，边界清晰，避免信息打架
1. 推送到【今日作业】：适合学科作业、书面任务。**家长、授权老师都可以写入**
    - 规则：支持【覆盖原有今日作业】 / 【追加到原有作业末尾】两个选项（非常重要！）
      - 覆盖：今天换新作业，清空旧的
      - 追加：老师先布置一部分，晚上再补充几条，不用重输一遍
2. 推送到【老师便签】：适合临时通知、测验提醒、带物品通知（明天小测、带草稿本）
    - 规则：老师优先使用这个通道；家长也可以在这里写自己的备注
    - 便签支持多条，每条自带发送人标记「👩‍🏫老师」「👨👩家长」，A屏展示时区分来源，学生一眼看懂是谁发的

### 3.4 时间自动生命周期（极大减少家长清理负担，产品化加分项）
> 自动过期机制，**不需要家长每天手动清空昨天的作业**
- 今日作业：到当天24点，系统自动归档到历史记录，次日模块清空，等待新作业推送
- 老师便签：支持两种模式：
  - 单次通知：当日24点自动归档消失
  - 持续便签（老师/家长勾选）：持续展示，直到手动删除（例如：下周带艺术节道具）
- 归档：所有历史作业、历史便签，在Web后台和小程序都有【历史记录】，可以回看、复制复用（直接复制昨天的作业，修改几条就变成今天的）

> 这个功能解决最大痛点：家长最怕每天还要手动删昨天的内容。系统自动轮转。

### 3.5 推送之后，墨水屏生效逻辑
1. 推送成功 → 后端更新模块内容，生成新版A屏快照
2. A屏两种生效路径：
   - 定时自动刷新（家长设置的A屏间隔：15/30/60min），到点拉取
   - 小程序内【立即同步A屏】按钮（受5分钟限流保护，保护快刷屏）
3. B屏不受作业推送影响：B屏只在每日08点定时刷新，作业不会跑到B屏

### 3.6 老师授权流程（完整闭环，适合班级推广）
1. 家长在Web后台【授权管理】→ 新增老师授权
   - 选项：授权名称（比如：王老师）、授权有效期【7天/30天/永久】、可推送范围：仅老师便签 / 允许推送今日作业
   - 系统生成：6位数字授权码 + 微信小程序二维码
2. 家长把二维码+授权码发给任课老师
3. 老师微信扫码打开小程序 → 选择【老师快捷推送】→ 输入6位授权码，直接进入该学生的推送面板
4. 老师操作：粘贴/OCR作业、写通知，一键推送；**看不到这个设备的课程表、倒计时、模式、其他配置**
5. 家长随时可以在后台：冻结、撤销授权；授权过期自动失效。
> 优势：无注册、无手机号收集、零门槛，学校老师愿意用，是产品核心差异化卖点。

## 六、数据表新增字段（推送、授权、生命周期）
1. `device`：student_stage学段、screen_b_fixed_refresh_time、a_refresh_interval
2. `mode`、`mode_module_rel`：原有+新增screen_bind(A/B/auto)
3. `module_content`：原有
4. `push_record`【新增推送记录表】
    - id、device_sn、push_type（homework / note）、sender_type(parent/teacher)、sender_name、content、is_append(0覆盖/1追加)、expire_time、create_time
5. `teacher_auth`【授权表】
    - id、device_sn、auth_code、auth_name、permission(only_note / note_and_homework)、expire_time、is_frozen
6. `svg_snapshot_a`、`svg_snapshot_b`：两套快照缓存

## 七、接口简要说明（支撑双端推送）
1. 小程序侧
    - `POST /api/push/homework` 推送今日作业（覆盖/追加）
    - `POST /api/push/note` 推送老师便签
    - `GET /api/push/history` 查询历史推送记录
    - `POST /api/auth/verify` 老师授权码校验
2. 设备侧
    - `GET /api/device/snapshot_a?sn=xxx` A屏快照
    - `GET /api/device/snapshot_b?sn=xxx` B屏快照
3. Web后台：模式、授权、素材、归档管理接口

## 八、异常与风控（产品化必须考虑）
1. 授权码防泄露：6位数字，支持随时冻结；后台日志记录每一次授权登录、推送记录
2. OCR容错：识别失败提示手动输入；长文本自动换行，适配4.2寸屏宽度
3. 推送内容长度限制：后台设置最大字符上限，超长时提示精简，防止墨水屏排版溢出
4. 断网兜底：A/B屏保留上一版快照；联网后自动拉取新版本
5. 刷屏保护：A屏强制同步限流5分钟一次；B屏仅开放后台独立强制刷新按钮，不向小程序开放B屏刷新，避免误操作损耗慢刷屏

## 九、商业化卖点整理（淘宝/众筹/宣讲直接用）
1. 一体双墨水屏架构：B屏静态大盘，课程表、倒计时全天可见；A屏交互式任务菜单，孩子自主翻看当日任务
2. 学段智能过滤，菜单自动精简：小学/初中/高中自动屏蔽无关模块，不用繁琐关闭功能
3. 微信小程序极速推送作业：文字粘贴、图片OCR识别两种方式，班级群作业一键上屏
4. 老师免注册授权推送：家长生成授权码发给老师，老师可以下发作业和通知，权限可控、随时回收
5. 自动作业生命周期：当日作业24点自动归档，无需每日手动清理；历史记录可回看、一键复用
6. 模式 +/- 自定义配置，Web后台深度定制，适配冲刺、日常等不同学习阶段
7. 无蓝光、无弹窗、无娱乐内容，纯信息看板；断网不掉画面

# 补充落地建议（独立段落，不在md内，给你决策参考）
1. **优先主推小程序OCR+粘贴推送**，这是最打动家长的点。很多家长痛点就是：班级群图片作业，保存、打字非常麻烦。
2. 关于「追加/覆盖」选项，默认推荐 **追加**，家长手动勾选才是覆盖。老师经常分批布置作业，追加更贴合真实场景。
3. 老师权限做保守设计：默认授权只能发便签，家长主动勾选才允许老师推送作业，规避老师误删原有作业的风险。
4. 归档历史可以做一个「复制为今日作业」按钮，周末预习、周循环作业直接复用，进一步降低录入成本。
5. 学生不开放勾选权限是权衡后的选择；如果你后续想提供可选开关，我可以再加一个配置项【是否允许小程序/屏幕端学生打卡】，作为增值选项。
