# 森穹小悟 · 一体双屏学习墨看板 全套PRD V1.4
> 包含：主产品PRD + 微信小程序原型 + Web管理后台原型
> 硬件：一体双4.2寸墨水屏
> A屏：黑白快刷｜按键菜单交互、当日动态任务视图，本地预缓存全部视图，按键切换不上云
> B屏：慢刷屏｜每日定时刷新1次（默认08:00），静态大盘（课程表、总倒计时、月度考试历）
> 过滤优先级：学段过滤 → 模式 +/- 开关 → 模块A/B屏归属分流
> 按键：上 / 下 / OK；学生仅浏览，无编辑权限

| 角色 | 权限范围 | 登录入口 |
| ---- | ---- | ---- |
| 平台管理员 | 设备SN入库、固件升级、账号风控、后台配置参数 | Web后台 |
| 家长【主账号，设备持有人】 | 绑定双屏设备、设置学段、管理模式、全部模块内容录入、生成老师临时授权码、查看推送记录、强制刷新A/B屏 | Web后台 + 微信小程序 |
| 授权老师【临时/长期】 | 仅推送：老师便签、班级统一作业；不能修改课程表、倒计时、学段、模式；一个授权只绑定这一台学生设备 | 微信小程序（免注册，授权码登录） |

# 二、三层过滤体系
1. **第一层：学段过滤（家长设备页设置：小学 / 初中 / 高中，系统自动白名单）**
    不在学段白名单的模块，在后台隐藏、不进入菜单池
2. **第二层：模式 +/- 开关**
    学段允许的模块，家长继续开启`+` / 关闭`-`
3. **第三层：A/B屏分流（系统默认，支持手动覆盖）**
    - B屏（日更一次，08:00定时刷新）：课程表、倒计时组、月度考试历
    - A屏（快刷菜单视图，本地缓存切换）：书包物品提醒、今日作业、老师便签、背诵打卡、错题复盘、周固定任务、阅读任务、作文素材、公式速查、积分看板、护眼提示

# 三、作业 & 老师任务推送方案
> 核心结论：双入口：家长快捷推送入口 + 老师授权推送入口；支持3种录入方式，满足不同场景
> 推送目标：【今日作业】模块、【老师便签】模块。两个模块是信息交汇点，互不冲突。

## 3.1 推送入口载体：微信小程序
Web后台用于长期配置（课程表、模式、学段、素材库、授权管理）；
小程序用于每日高频推送（作业、临时通知），手机随手发，适合家长、老师。

## 3.2 三种录入方式（由简到繁）
### 方式1：文本直接粘贴（最高频，主推）
家长/老师把微信群、班级群里复制好的作业文本，直接粘贴到输入框，支持换行。
示例粘贴内容：
数学：P42 1-12 题
英语：背诵 Unit8 单词，听写
物理：完成周测剩余大题
系统自动保留换行格式，直接落库到【今日作业】或者【老师便签】。不需要手动选择科目、增加条目，粘贴即推送。

### 方式2：拍照OCR识别（第二主推，解决老师发图片作业）
小程序内置OCR：直接拍摄班级群作业图片 → 识别文字 → 用户可以简单修改识别结果 → 一键推送至设备。
> 商业化备注：OCR调用按量计费，后台可配置额度；识别结果允许人工校正，防止错字。

### 方式3：模板快捷选择（周期性任务、固定作业）
后台【素材库】支持家长保存个人作业模板。
示例模板：英语听力20min、练字15分钟。小程序直接勾选模板，一键追加到今日作业。

## 3.3 两个推送目标，边界清晰
1. 推送到【今日作业】：适合学科作业、书面任务。家长、授权老师都可以写入
    - 选项：【覆盖原有今日作业】 / 【追加到原有作业末尾】（默认追加）
2. 推送到【老师便签】：适合临时通知、测验提醒、带物品通知
    - 模式：单次通知（当日24点消失） / 持续便签（家长专属，手动删除）
    - A屏展示区分来源：👩‍🏫老师 / 👨👩家长

## 3.4 时间自动生命周期
- 今日作业：到当天24点，系统自动归档到历史记录，次日模块清空，等待新作业推送
- 老师便签：
  - 单次通知：当日24点自动归档消失
  - 持续便签（家长勾选）：持续展示，直到手动删除
- 归档记录：Web后台和小程序都可回看、复制复用

## 3.5 推送之后，墨水屏生效逻辑
1. 推送成功 → 后端更新模块内容，生成新版A屏快照
2. A屏两种生效路径：
   - 定时自动刷新（15/30/60min）
   - 小程序内【立即同步A屏】按钮（5分钟限流）
3. B屏不受作业推送影响：B屏只在每日08点定时刷新

## 3.6 老师授权流程
1. 家长Web后台【授权管理】→ 新增老师授权
   - 参数：授权名称、有效期【7天/30天/永久】、权限：仅便签 / 便签+追加作业
   - 输出：6位数字授权码 + 微信小程序二维码
2. 家长发给老师
3. 老师扫码打开小程序 → 老师快捷推送 → 输入6位授权码，进入推送面板
4. 家长随时冻结、撤销授权；授权过期自动失效

# 五、数据表设计摘要
1. `device`：sn、name、student_stage、screen_b_refresh_time、a_refresh_interval、firmware_version、online_status
2. `mode`：mode_id、name、is_preset
3. `mode_module_rel`：mode_id、module_name、enable、screen_bind(auto/A/B)、sort_index
4. `push_record`：id、device_sn、push_type(homework/note)、sender_type(parent/teacher)、sender_name、content、is_append、expire_time、create_time
5. `teacher_auth`：id、device_sn、auth_code、auth_name、permission、expire_time、is_frozen
6. `svg_snapshot_a`、`svg_snapshot_b`：快照缓存表

# 六、接口摘要
## 小程序侧
- `POST /api/push/homework` 推送今日作业（覆盖/追加）

## 设备侧
- `GET /api/device/snapshot_a?sn=xxx` A屏快照
- `GET /api/device/snapshot_b?sn=xxx` B屏快照

# 九、风控&约束汇总
1. 学段切换自动过滤模块池，无关模块隐藏置灰
2. B屏刷新权限隔离，小程序不能强制刷B屏

4. 内容长度校验，超长提示精简，防止墨水屏排版溢出
5. 快照版本比对：内容不变，复用缓存，不重复渲染SVG
6. 设备解绑时，该设备全部授权码自动失效
