小智墨水屏 TF 卡电子书规则

1. TF 卡格式：FAT32（推荐），也可使用 FAT16。
2. 电子书目录：/xiaozhi/books/
3. 支持格式：UTF-8 编码的纯文本文件，扩展名 .txt 或 .md。
4. 单本文件最大：2 MB。
5. 建议文件名使用中文、英文、数字、空格，例如：小王子.txt。
6. 不支持 EPUB、MOBI、AZW3、PDF、DOCX；请先在电脑上转换为 UTF-8 TXT。
7. 设备挂载 TF 卡时会自动创建 /xiaozhi/books/ 目录。
8. 插图（可选，两种写法等价）：在文中插入 PNG 图片页，图片放到
   /xiaozhi/books/ 目录，翻到该页时全屏显示，按上/下键继续。
   - TXT/MD 均可写：[[img:图片名.png]]
   - Markdown 标准写法（.md 推荐）：![插图说明](图片名.png)
   - 目前仅支持 PNG（不支持 JPG），单张建议不超过 400x300。
   - 路径写法会被忽略目录部分，图片必须和 TXT 放同一目录。
   示例（小王子.md）：

       第二章 到星球去
       ……正文……
       ![六号星球](xingqiu6.png)
       ……正文继续……

操作：
- 主页用上下键选择“阅读”，按 OK 打开书库中的第一本 TXT。
- 阅读时按上键上一页，按下键或 OK 下一页。
- 长按 OK 返回主页。

==============================================
单词功能（闪卡背单词）
==============================================

1. 词表文件：/xiaozhi/words/words.txt（UTF-8，最大 512 KB）。
2. 每行一个单词，逗号分隔：

       单词,音标,词性,释义,例句

   音标/词性/例句可留空，释义不能为空；# 开头的行是注释。
   示例：

       ambiguous,/æmˈbɪɡjuəs/,adj.,模糊的；模棱两可的,an ambiguous reply
       praise,,,,表扬 赞美

3. 界面与按键：
   - 学习卡：标题显示 单词 序号/总数 · 连续打卡天数；带 [今日] 的是
     每天自动轮换的“今日单词”。上/下键换词，浏览过的词自动记为学过。
   - OK 开始回忆测试：只显示单词和“几天前学过”，想好意思后按 OK 揭示；
     上键=记得，下键=忘了（记分后自动进入记忆统计页，任意键返回）。
   - OK 在回忆页=看答案/跳过。长按 OK 返回主页。
   - 单词页 OK 不再唤起小智；唤醒请用语音“你好小智”或先长按返回主页。
4. 记忆统计保存在设备上：今日记得/忘了、连续打卡、累计正确率、最近记录。
